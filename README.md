# Landing Page ETLCSYSTEMS

Una página profesional desarrollada por los ingenieros Luis y Erickson.

## Descripción

Landing Page moderna construida con React + Vite, Tailwind CSS y animaciones personalizadas. Ideal para presentar servicios y portafolio de ETLCSYSTEMS.

## Recursos principales

- React 18
- Vite
- Tailwind CSS
- Animaciones personalizadas en `src/components`
- Tema oscuro/claro y cursor personalizado

## Cómo ejecutar

```bash
npm install
npm run dev
```

## Estructura del proyecto

- `src/App.jsx`
- `src/components/`
- `src/index.css`
- `tailwind.config.js`
